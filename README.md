# Instructions
**These are add-ons for the Balatro Multiplayer Mod ONLY**
**Currently only supported in EN-US**

1. There are 3 parts to each Joker:
   
   a. Main LUA Joker file

   b. 1x .PNG
   
   c. 2x .PNG
   
   d. Description File Add-on

2. Drop Main LUA Joker File in %appdata% > Balatro > Mods > multiplayer-x.x.x > objects > jokers
   
3. Drop each Xx .PNG File in its corresponding folder in %appdata% > Balatro > Mods > multiplayer-x.x.x > assets > 1x or 2x
   
   a. Ensure the name of the image file is j_[joker].png regardless of size (1x or 2x)

4. Modify localization file to enable joker description by adding the localization text for each joker under en-us.lua in localization folder

   a. ... > multiplayer-x.x.x > localization > en-us.lua

5. Open the game and enjoy
